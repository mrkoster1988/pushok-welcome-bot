# История изменений

## 0.1.0-alpha.6 — 2026-11-12

- Постоянная очередь ответов Telegram/VK и тестового MAX polling; общая отправка с MAX webhook.
- Восстановление pending после перезапуска, sending → uncertain без автоматической повторной отправки.
- CLI delivery.py: status, ручное закрытие uncertain, просмотр и очистка завершённых ответов с блокировкой базы.
- Очистка сохраняет ID обработанных событий и все незавершённые ответы.
- Лимит 20 команд обычного участника за минуту, /setlimit 0–120; счётчики переживают перезапуск.
- Пауза приветствий 30 секунд на чат, /welcomecooldown 0–86400; события внутри паузы пропускаются.
- /setup: проверка сохранённых настроек с подсказками, только для администратора.
- 128 тестов; новые проверки аварий, CLI, лимитов, очистки и проверки в Docker, включая настоящий HTTP webhook.
- DELIVERY.md: десять шагов выпуска, обновление с alpha.5 и приёмка. Реальная доставка и VPS не подтверждены.

## 0.1.0-alpha.5 — 2026-11-12

- FAQ: добавление, редактирование, удаление, страницы списка, просмотр и поиск по вопросам/ответам.
- Автоприветствие с отдельным текстом и включением на каждый чат; по умолчанию выключено.
- События вступления Telegram new_chat_members, MAX user_added и VK chat_invite_user / chat_invite_user_by_link с member_id.
- Тип события отделён от текста команды; повторные события не создают второй ответ. Старые очереди команд совместимы.
- Инструкция WELCOME.md с настройкой, ограничениями и приёмкой. Для MAX webhook требуется обновить подписку того же URL.
- 94 автоматических теста; контейнерная проверка дополнена FAQ и приветствием. Реальная доставка не подтверждена.

## 0.1.0-alpha.4 — 2026-11-12

- Резервное копирование работающей SQLite через Backup API, проверка SHA-256 и целостности.
- Восстановление в новый файл без перезаписи; права 0600 и исключение копий из Git/Docker.
- Привязка базы к проекту; восстановленная база блокирует запуск до явной активации.
- Старая очередь после активации остаётся held, чтобы избежать автоматической повторной отправки.
- 74 локальных теста на проект, включая 21 проверку копирования, WAL, восстановления и блокировки запуска.
- CI собирает оба Docker-образа и проверяет backup/restore внутри контейнеров без сети.
- Инструкция backup/restore для Telegram, MAX webhook и VK. Доставка и запуск на VPS не проверены.

## 0.1.0-alpha.3 — 2026-11-12

- MAX webhook: проверка секрета и HTTP-запроса, постоянная SQLite-очередь.
- Отдельный worker; команда, ID события и ответ сохраняются одной транзакцией.
- Восстановление ожидающих ответов; uncertain без автоматического повтора при неизвестном исходе отправки.
- Регистрация подписки без замены чужого URL, health/status, Docker Compose и пример Caddy.
- 53 автоматические проверки на проект, включая 21 проверку webhook; локальный HTTP smoke через Gunicorn.
- Реальная доставка, сборка Docker и HTTPS на VPS ещё не проверены.

## 0.1.0-alpha.2 — 2026-11-12

- Текстовые адаптеры MAX (тестовый polling) и VK Bots Long Poll.
- Проверка конфигурации, отдельные права и разрешённые чаты по платформам.
- Сохранение курсора, привязка базы к боту, восстановление ключа VK Long Poll.
- Проверки схем событий, отказов, повторов и профильного сценария через новые адаптеры.
- Выбор платформы Docker, инструкция подключения и обновления.
- Реальные токены, доставка и production webhook MAX пока не проверены/не реализованы.

## 0.1.0-alpha.1 — 2026-11-12

- Первый отдельный сценарий: Помощник новичка.
- Локальная демонстрация, Telegram long polling, SQLite.
- Изоляция чатов, права из конфигурации, защита от повторного применения событий.
- Тесты и инструкция. Реальная доставка ещё не проверена.
